# AI Portfolio

A one-file portfolio with an AI that answers visitors' questions about you. Plain HTML, hosted free on GitHub Pages, no backend.

Live demo: https://fengyiqicoder.github.io/my-portfolio/

## Use it

1. Click **Use this template**, then **Create a new repository**.
2. Open `index.html`, replace `YOUR_ONETAG_KEY` with a free key from [onetagai.com](https://onetagai.com), and rewrite the `#about` section with your own name, projects and contact.
3. In **Settings → Pages**, set Branch to `main` and save. Your site is live at `https://<username>.github.io/<repository>/`.

The AI reads only what is inside `#about`. Change the text and the answers change.

Powered by [OneTag AI](https://onetagai.com).
